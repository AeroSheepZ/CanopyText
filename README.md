# 转换器

CanopyDeck 的外部工具。打开之后是一页，JSON、Base64、URL、时间各占一块。

在 CanopyDeck 的插件页填写 `AeroSheepZ/CanopyText` 安装。

## JSON

美化和压缩写回同一块文字。合法 JSON 按词着色：键、字符串、数字、布尔值和 null 各有颜色。排序键默认开着，关掉后保留原来的键序。缩进是两格。

## Base64

文本和 Base64 上下两块，改一边另一边跟着变，也可以对调。URL-safe 把 `+` `/` 换成 `-` `_`，并且去掉末尾的 `=`。

## URL

默认按片段编码，`https://` 里的冒号和斜杠也会编掉。整段保留网址结构，空格变成 `%20`。

## 时间

本地时间、秒、毫秒三行连在一起，改一行另外两行跟着变。秒是 10 位，毫秒是 13 位。本地时间认 `2026-10-17 11:14:00`，也认带时区的 ISO 8601，包括 `2026-10-17T03:14:00.123Z` 这种带小数秒的写法。点「现在」写入当前时刻。
